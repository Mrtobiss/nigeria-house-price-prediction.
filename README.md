# Nigeria House Price Prediction

A machine-learning system that estimates the **asking price (₦)** of a residential property in Nigeria from its
state, town, property type and room counts. The selected model is served through a Streamlit app.

- **Problem type:** supervised regression (target: asking price in Naira, modelled on the log scale)
- **Data:** `nigeria_houses_data.csv`, 24,326 property listings, 8 columns (bedrooms, bathrooms, toilets, parking
  spaces, property type, town, state, price)

## Method in brief

1. **Clean.** "Anambara" state labels attached to towns in other states were reassigned using exact-match twins and
   majority geography. Exact repeated listings were removed. The data was then split 80/20 (stratified by region).
   Records priced more than 10 times above or below the median of comparable listings (same town and type; reference
   computed from the training split only) were removed from modelling. Every excluded row keeps a recorded reason.
2. **Model.** Two baselines (global median, town-and-type median) and Ridge, Random Forest and Gradient Boosting are
   compared with 5-fold cross-validation on the training set; the strongest are tuned; the test set is used once.
3. **Evaluate.** MAE, RMSE and R2 on log price, median percentage error and share of predictions within 30%, on a random
   hold-out set; error by region and by town data volume; permutation importance.
4. **Deploy.** The model is saved with `joblib`; the app's prediction code is checked against the saved model and covered
   by unit tests.

## Headline result (Gradient Boosting, random hold-out set of 2,714 listings)

R2 (log price) 0.76 · median error 31% · 49% of predictions within 30% of the actual asking price.
Scores apply to the retained price range (records more than 10 times away from comparable listings were removed).

## Deploy on Streamlit Community Cloud

1. Push this repository to GitHub, **including `models/model.joblib` and `models/model_meta.json`**.
2. On [share.streamlit.io](https://share.streamlit.io) choose *New app*, select the repository, branch `main` and main file `app.py`.
3. Under *Advanced settings*, choose a Python version matching `models/model_meta.json` -> `versions.python` (the model was trained with that version).
4. Paste the app link into this README.

## Assumptions and limitations

- Prices are **asking prices**, not confirmed sale prices.
- There is no property size, age, condition, address or date in the data. Identical-looking listings differ widely in
  price, which sets a ceiling on accuracy (estimated in the notebook, Task 22).
- Most listings are in Lagos and Abuja. Estimates for other states and for towns with few listings are less reliable and the app says so.
- The model was not validated on towns it has never seen; the app offers only towns present in the training data.
- Exact repeated listings were treated as duplicates; with no listing ID this is an assumption.
- Extreme prices were removed by a documented rule, so scores describe the retained range only.
- The model estimates the *typical* asking price for a property like the one described and is not a valuation.
